# Prabhakar Tambulkar Portfolio — Single File

This version is designed for GitHub Pages when you want the simplest possible upload.

## Upload
Upload **only `index.html`** to the root of your GitHub repository.

All CSS and portfolio images are embedded inside `index.html`, so there is no `assets` folder to upload and no broken-image path problem.

Before publishing, replace `YOUR_EMAIL@example.com` in the file with your actual email.

## GitHub Pages
Repository → Settings → Pages → Deploy from branch → `main` → `/ (root)` → Save.
