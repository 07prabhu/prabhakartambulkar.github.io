# Prabhakar Tambulkar — Portfolio

This is a static GitHub Pages portfolio built with HTML and CSS.

## Files
- `index.html` — website structure and content
- `style.css` — complete responsive design
- `assets/` — professional profile and portfolio photographs

## GitHub Pages
Upload `index.html`, `style.css`, and the entire `assets` folder to the root of your repository.

Important:
1. Keep the `assets` folder name exactly as shown.
2. Replace `YOUR_EMAIL@example.com` in `index.html` with your real email.
3. Replace/add your LinkedIn profile URL when ready.
4. Commit the changes to `main`.
5. Refresh your GitHub Pages site.

The speaking photos have been lightly cropped to remove phone/video-player UI bars.
